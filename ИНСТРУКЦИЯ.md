# Maria Flora — инструкция по запуску и редактированию

Проект состоит из двух частей:

| Адрес | Что это |
|---|---|
| `http://localhost:3000/` | Сайт с меню: визитка (фото с «солнцем», соцсети, био, 3D-карусель), 6 букетов, 4 бокса, мастер-классы, FAQ, контакты. Старый адрес `/shop` ведёт к букетам |
| `http://localhost:3000/crm` | Мини-CRM (пароль `maria2026`) |

Все заявки с сайта (кнопка «Заказать» и «Забронировать место») сохраняются в базу
`data/maria-flora.db` (SQLite) и сразу появляются в CRM в колонке «Новая заявка».

---

## 1. Запуск

Нужен Node.js **22.13 или новее** (сейчас стоит 22.23).

```bash
cd "C:\Users\User\Desktop\Кейс1\maria-flora"
npm install          # только в первый раз
npm run build        # собрать сайт (после каждого изменения файлов)
npm run start        # запустить → http://localhost:3000
```

Для правок «на лету» удобнее `npm run dev`: изменения видны сразу после сохранения файла, без пересборки.

> Сборка идёт через Turbopack (флаг уже прописан в `package.json`). Обычный webpack-сборщик Next.js
> ломается на кириллице в пути (`Кейс1`), поэтому `--turbopack` из команд не убирайте.

## 2. Реальные данные и ссылки (главное)

Всё, что нужно заменить, собрано в **трёх файлах** в папке `config/`. Код трогать не нужно.
Пустая строка `""` значит «ссылка ещё не подключена»: кнопка не ломается, а показывает посетителю
вежливое сообщение. Вписали ссылку — кнопка начала вести по ней.

### 2.1. `config/site.ts` — контакты, соцсети, фото, запись

| Поле | Что вписать | Пример |
|---|---|---|
| `photo` | путь к фото Марии (файл положить в `public/img/`) | `"/img/maria.jpg"` |
| `contacts.phone` | телефон, как показывать на сайте | `"+1 (313) 456-78-99"` |
| `contacts.email` | почта | `"maria@mariaflora.com"` |
| `contacts.deliveryArea` | зона доставки (подвал) | `"Портленд и пригороды в радиусе 20 миль"` |
| `social.tiktok` | профиль TikTok | `"https://www.tiktok.com/@mariaflora"` |
| `social.telegram` | Telegram (личный или бот) | `"https://t.me/mariaflora_bot"` |
| `social.pinterest` | Pinterest | `"https://www.pinterest.com/mariaflora"` |
| `social.whatsapp` | WhatsApp | `"https://wa.me/13134567899"` |
| `social.instagram` | Instagram (заготовка, на сайт пока не выведен) | `"https://www.instagram.com/mariaflorastudio"` |
| `masterclassBookingUrl` | страница записи в Google Календаре | `"https://calendar.app.google/XXXX"` |

**WhatsApp:** формат `https://wa.me/` + номер **только цифрами** с кодом страны, без `+`, пробелов и скобок.
Можно сразу подставить текст сообщения: `https://wa.me/13134567899?text=Здравствуйте!%20Хочу%20букет`.

**Фото Марии:** квадратное, от 800×800 px, лицо по центру (обрезается в круг). Пока `photo` пустой,
на месте фото стоит монограмма «MF».

**Запись на мастер-класс через Google Календарь:**
1. Откройте calendar.google.com → «Создать» → **«Расписание встреч» (Appointment schedule)**.
2. Задайте длительность, доступные даты и время, сохраните.
3. Нажмите «Открыть страницу бронирования» → скопируйте ссылку → вставьте в `masterclassBookingUrl`.

Когда ссылка вписана, кнопка «Забронировать место» ведёт в календарь, а под ней появляется
«или оставить заявку на индивидуальное занятие» (эта форма по-прежнему пишет в CRM).
Пока ссылки нет, кнопка сразу открывает форму заявки.

### 2.2. `config/products.ts` — товары, цены, фото, ссылки на оплату Stripe

У каждого товара есть поля `name`, `price`, `description`, `image`, `paymentUrl`.

**Как подключить оплату Stripe (Payment Links):**
1. Зарегистрируйтесь на stripe.com, заполните данные бизнеса (без этого живые платежи не включатся).
2. **Product catalog → + Add product**: название (например, `Cascadian Wild`), цена `150 USD`, One-off.
3. На странице товара: **Create payment link**.
   - В разделе «Options» включите **Collect customers' addresses** (адрес доставки) и сбор телефона.
   - Во вкладке **After payment** выберите «Don't show confirmation page → Redirect customers to your website»
     и укажите адрес сайта, например `https://ваш-домен/?paid=1`.
4. Скопируйте ссылку вида `https://buy.stripe.com/xxxxxxxx` и вставьте в `paymentUrl` этого товара:

```ts
{
  slug: "cascadian-wild",
  ...
  paymentUrl: "https://buy.stripe.com/xxxxxxxx",
},
```

5. Повторите для всех 10 товаров. Для проверки используйте **Test mode** в Stripe
   (тестовая карта `4242 4242 4242 4242`, любая будущая дата и любой CVC),
   а перед запуском переключитесь в Live и замените ссылки на «живые».

Как работает заказ на сайте:
- **ссылка вписана** → клиент заполняет форму (имя, фамилия, телефон, email, адрес) → заявка падает в CRM →
  появляется кнопка **«Перейти к оплате»** → Stripe;
- **ссылки нет** → заявка всё равно падает в CRM, клиент видит, что Мария пришлёт ссылку на оплату лично.

Когда клиент оплатил, Маша вручную переносит карточку в «Оплачено»
(автоматический перенос по вебхуку Stripe — следующий шаг, см. раздел 6).

**Добавить новый товар:** положите фото в `public/img/` (квадрат, около 1000×1000, JPG до 300 КБ),
скопируйте блок любого товара в `bouquets` или `gifts`, поменяйте `slug` (латиницей, без пробелов, уникальный),
название, цену, описание, путь к фото. Сетка подстроится сама. В карусель на визитке попадают все букеты
из `bouquets`.

**Удалить товар:** удалите его блок `{ ... },` целиком.

### 2.3. `config/content.ts` — био и FAQ

- `bio` — текст, который «печатается» на визитке.
- `faq` — список вопросов: каждый элемент `{ q: "вопрос", a: "ответ" }`. Порядок на сайте такой же.

Тексты сайта (заголовок Hero, описание мастер-классов) лежат прямо в
`app/page.tsx` и `components/ShopSections.tsx`: найдите нужную фразу поиском и замените.

## 3. Мини-CRM

### Пароль
Файл `.env.local`:
```
CRM_PASSWORD=maria2026
CRM_SECRET=длинная-случайная-строка
```
Чтобы сменить пароль, поменяйте `CRM_PASSWORD`, а заодно и `CRM_SECRET` (тогда старые входы сбросятся),
и перезапустите сервер. После входа пароль не спрашивается, пока браузер открыт.

### Что умеет доска
- 6 колонок: Лид → Новая заявка → В работе → Ссылка отправлена → Оплачено → Закрыта.
- Карточки перетаскиваются мышкой между колонками.
- Сверху крупный счётчик новых заявок и фильтр по статусам (можно выбрать несколько).
- **«Скачать CSV»**: при включённом фильтре выгружает только видимые карточки, без фильтра выгружает всю базу.
  Колонки: имя, Telegram, телефон, email, адрес, тип, статус, дата. Открывается в Excel и Google Таблицах.
- Клик по карточке делит экран: слева карточки этой колонки, справа переписка в стиле Telegram,
  кнопки статусов, контакты (редактируются, сохраняются при клике вне поля) и заметки Маши.
- Непрочитанные карточки подсвечены и отмечены пульсирующей точкой. Отметка снимается, когда карточку открыли.
- Если ответить на «Новую заявку», карточка сама переходит «В работу».
- Доска обновляется каждые 8 секунд, новые заказы с сайта появляются без перезагрузки.

### Демо-карточки
При первом запуске в базу добавляются 5 примеров (помечены «Пример»). Удалить их:
```bash
npm run clear-demo
```
Чтобы новая пустая база создавалась без примеров, добавьте в `.env.local` строку `SEED_DEMO=0`.

### База данных
- Файл: `data/maria-flora.db` (SQLite). Таблицы `leads` (карточки) и `messages` (переписка).
- **Резервная копия:** остановите сервер и скопируйте файлы `data/maria-flora.db*` в надёжное место.
- **Начать с чистого листа:** остановите сервер и удалите `data/maria-flora.db*`. При следующем запуске база создастся заново.
- Открыть и посмотреть таблицы можно бесплатной программой **DB Browser for SQLite**.

## 5. Публикация в интернет

Сейчас всё работает локально. База — это файл на диске, поэтому хостинги без постоянного диска
(Vercel, Netlify) не подойдут: база будет стираться. Варианты:

1. **VPS или Railway / Render / Fly.io с подключённым диском (volume).** Залить папку проекта,
   выполнить `npm install && npm run build && npm run start`, примонтировать диск и указать путь к базе
   переменной `DB_PATH=/data/maria-flora.db`. Добавить в переменные окружения `CRM_PASSWORD` и `CRM_SECRET`.
2. **Переезд базы в облако (Supabase/Postgres)**, если нужен Vercel. Для этого переписывается только
   `lib/db.ts`, интерфейс и API остаются прежними.

После публикации поменяйте в Stripe адрес редиректа после оплаты на реальный домен.

## 6. Что подключить следующим шагом

- **Telegram-бот (урок 4):** создать бота в @BotFather и получить токен, добавить `TELEGRAM_BOT_TOKEN` в `.env.local`.
  Вебхук бота создаёт карточки через `createLead()` (source `telegram`) и добавляет сообщения клиента
  через `addMessage()`. Ответ Маши из CRM (`app/api/crm/leads/[id]/messages/route.ts`) дополнительно
  отправляется клиенту методом `sendMessage`. Поле `tg_username` в карточках уже есть.
- **Вебхук Stripe:** событие `checkout.session.completed` → найти карточку по email → статус `paid`.
- **AI-ассистент (уроки 2–3, 9):** база знаний Maria Flora уже совпадает с каталогом сайта по названиям и ценам.
